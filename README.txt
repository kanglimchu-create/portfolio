KIanna LIM — IT PORTFOLIO
==========================

FILES
-----
index.html  - Page content and sections
style.css   - Colors, layout, animations, responsive/mobile styles
script.js   - JavaScript interactions
images/     - Includes your profile photo (kianna-profile.jpg)

HOW TO OPEN
-----------
1. Extract the ZIP file.
2. Open the extracted folder in VS Code.
3. Open index.html in a browser, or use the Live Server extension.
4. Keep index.html, style.css, and script.js in the same folder.

MOBILE NAVIGATION
-----------------
The navigation bar remains visible at the top on mobile screens. If all links do
not fit on a narrow phone, swipe the navigation row horizontally. It is not hidden
behind a hamburger menu.

PERSONALIZE YOUR PORTFOLIO
--------------------------
- Replace the sample email in index.html with your real email.
- Replace the GitHub and LinkedIn URLs with your profile links.
- Your profile photo is already included as images/kianna-profile.jpg. To change it, replace that file with your preferred photo using the same filename.
- Upload project previews using each "Add project preview" control.
- Update project details in script.js and page text in index.html.

IMPORTANT ABOUT UPLOADS
-----------------------
The upload controls show a temporary preview in the current browser tab. They do
not permanently save the image into your website files. To use a picture on the
published website:
1. Copy the image into the images folder.
2. In index.html, use a relative path such as images/profile.jpg.
3. Keep the image file with the website when you move or publish the folder.

The portfolio uses Google Fonts when internet is available; system fallback fonts
are defined for offline use. No framework or build step is required.
